# Papelaria Futura

Sistema de orçamentos, vendas, caixa, comissões, ordens de serviço, entregas e administração.

Consulte o [manual do projeto](docs/MANUAL.md) para publicar, configurar permissões, operar os módulos e recuperar backups.

O site utiliza HTML, CSS e JavaScript com Firebase Authentication e Firestore. As configurações de publicação permanecem em `vercel.json` e `firebase.json`.

| Pasta | Conteúdo |
|---|---|
| `js/`, `css/`, `img/`, `os/` | Aplicação |
| `firebase/` | Regras e índices do banco |
| `data/` | Catálogos auxiliares |
| `docs/` | Manual consolidado |
| `tests/` | Verificações locais |
| `tools/` | Ferramentas de manutenção |
